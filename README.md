Yomiku is a modern Android application born from the union of **Komikku** and **ManLore**.
Thanks to the great work of all Komikku & Tachiyomi contributors, Yomiku provides a fast, seamless, and secure reading and tracking experience.

## 🌟 Key Features
- **ManLore Vault Integration**: Track progress, quests, XP, statistics, and wishlists directly within the app.
- **Turso Sync Engine**: High-performance Cloud synchronization and local storage without relying on legacy services.
- **Google Drive & ManLore Sync**: Simplified synchronization options in Settings.
- **Unified Navigation**: Switch effortlessly between your manga library and the ManLore Vault without leaving the application.
- **Clean & Modern Design**: Customized Material 3 theme and intuitive user experience.

## 🚀 Build & Workflow
Builds are automated via GitHub Actions using:
- **Node.js LTS (24.x)**
- **Java 17 (LTS)**
- **Gradle 9.x**
